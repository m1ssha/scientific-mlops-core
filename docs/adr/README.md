# Архитектурные решения ядра

Все записи имеют статус **proposed**: это предложения для обсуждения, а не утверждённая архитектура и не описание реализованных гарантий. При изменении решения следует обновить статус записи и зафиксировать причину или подготовить новую запись со ссылкой на заменённую.

| ADR | Тема |
| --- | --- |
| [0001](0001-core-platform-boundary.md) | Граница ядра и платформы |
| [0002](0002-mvp-scope.md) | Границы MVP и восстановления |
| [0003](0003-experiment-model.md) | Модель эксперимента |
| [0004](0004-version-identity.md) | Идентификация и неизменяемость версий |
| [0005](0005-storage.md) | Хранение метаданных и содержимого |
| [0006](0006-publication-concurrency.md) | Публикация и конкурентный доступ |
| [0007](0007-recovery.md) | План восстановления запуска |
| [0008](0008-comparison.md) | Сравнение экспериментов |
| [0009](0009-api-versioning.md) | Версионирование Go API |

Записи связаны между собой: при выборе способа хранения необходимо проверить совместимость модели идентификаторов и протокола публикации; границу восстановления и критерии сравнения следует уточнить на выбранном пайплайне.
