# Scientific MLOps Core

Проект ядра версионирования данных и вычислительных экспериментов. Пока здесь находится архитектурный черновик: программная реализация и тема учебной работы ещё не утверждены.

Ядро определяет, что считается версией датасета и описания эксперимента, как они связаны с конкретным запуском, как сравнить состояния и подготовить восстановление. Оно не управляет пользователями, веб-интерфейсом или вычислительным кластером.

Планируется использовать ядро как Go-модуль в [Scientific MLOps Platform](https://github.com/m1ssha/scientific-mlops-platform). Разделение репозиториев не требует разделения на два сетевых сервиса. Локальный CLI и файловые адаптеры позволят проверять ядро отдельно от платформы.
